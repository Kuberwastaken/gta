GTA 6's first update, **version 1.002.000**, began rolling out to pre-loaded copies on **Friday, November 13, 2026**, six days before launch. It is about **1.07 GB on PS5** and about **2.18-2.2 GB on Xbox Series X|S**, according to console download screens reported by VICE, KeenGamer and Timesaver. Rockstar has not posted patch notes.

## What do we know about update 1.002?

Everything here comes from what players see on their consoles, not from Rockstar <span class="tag-reported">reported</span>:

| | PS5 | Xbox Series X\|S |
| --- | --- | --- |
| Size | About 1.07 GB | About 2.18-2.2 GB |
| Rollout | Staggered: about 50% first, the rest about 11 hours later | Not reported as staggered |
| Mandatory | Reported as mandatory | Not stated |
| Patch notes | None | None |

The size gap between platforms is not explained. Xbox packages have run larger in store listings before, partly because of how the stores count gigabytes; see [[news/2026-11-10-gta-6-preload-live|our pre-load story]] for that detail.

## Is this the day-one patch?

VICE's headline calls it the day-one patch. Rockstar has not used that label and has not said whether more updates will arrive before Nov 19. We treat 1.002 as the first pre-launch update and keep the [[release/gta-6-day-one-patch|day-one patch page]] open for whatever comes next.

An insider account called "Text Funds 2" claims the update touches story data, executables, levels, shaders and scripts <span class="tag-rumour">rumour</span>. That is plausible for a late build, but nobody has shown it, and Rockstar has said nothing.

## What happened to the 15-50 GB patch predictions?

Before the update appeared, guesses that GTA 6 would need a 15-50 GB day-one patch circulated widely <span class="tag-rumour">rumour</span>. Update 1.002 is a fraction of that. That doesn't rule out a larger patch later, but the big-patch claim has no support yet. We log it in the [[leaks/index|leaks ledger]].

## Why does it matter?

Two reasons. First, if you pre-loaded and then switched off auto-downloads, you could hit a 1-2 GB download at midnight. Second, storage is tight: the base install already asks for up to 212 GB, and the [[guides/gta-6-storage-space-guide|storage guide]] explains how much headroom to leave for updates.

On PS5, check that auto-downloads are on and the console is in Rest Mode. On Xbox, turn on automatic updates and use Sleep mode. If you bought a boxed copy, redeem the code first; the box contains a code, not a disc ([[release/gta-6-physical-copy-no-disc|no disc explained]]).

- Rockstar patch notes, if any, before Nov 19.
- A second update in launch week, which Rockstar has not announced.
